# Actividad 3 — Programación Orientada a Objetos (POO) - Java

Repositorio creado para el desarrollo de la tercera actividad de Programación Orientada a Objetos, basada en los ejercicios 8.2 y 8.3 del libro *Ejercicios de programación orientada a objetos con Java y UML*, de Leonardo Bermón Angarita. Se aplican conceptos como clases, atributos, métodos, constructores, interfaces gráficas, herencia, encapsulamiento y diagramas UML.

## 📂 Estructura del Repositorio

El proyecto se encuentra organizado en carpetas independientes para cada ejercicio:

* 📁 **`Ejercicio8_2_Notas` — Análisis de notas**
  * **Descripción:** Aplicación con interfaz gráfica que permite ingresar cinco notas y calcular el promedio, la desviación estándar, la nota mayor y la nota menor.
  * **Ejercicios propuestos incluidos:** Validación de entradas no numéricas mediante alertas y advertencias cuando falta alguna de las cinco notas.
  * **Archivos principales:** `Notas.java`, `VentanaPrincipal.java`, `Principal.java`.

* 📁 **`Ejercicio8_3_Figuras` — Figuras geométricas**
  * **Descripción:** Aplicación con interfaz gráfica para calcular el volumen y la superficie de un cilindro, una esfera y una pirámide.
  * **Ejercicios propuestos incluidos:** Incorporación de un cubo y un prisma, además de imágenes ilustrativas de las figuras geométricas.
  * **Archivos principales:** `FiguraGeometrica.java`, `Cilindro.java`, `Esfera.java`, `Piramide.java`, `Cubo.java`, `Prisma.java`, `VentanaFigura.java`, `VentanaPrincipal.java` y `Principal.java`.
  * **Nota:** Se implementa un prisma rectangular, ya que el enunciado no especifica qué tipo de prisma utilizar.

## 📚 Conceptos de POO Aplicados

* **Clases:** Representan las notas y las figuras geométricas.
* **Atributos:** Almacenan las notas ingresadas, las dimensiones de las figuras y los resultados de los cálculos.
* **Métodos:** Realizan operaciones como calcular promedios, desviaciones estándar, volúmenes y superficies.
* **Constructores:** Inicializan los atributos de los objetos.
* **Objetos:** Se crean instancias de las clases para procesar información y realizar los cálculos.
* **Herencia:** Las clases de las figuras geométricas heredan de `FiguraGeometrica`.
* **Encapsulamiento:** Se utilizan modificadores de acceso para controlar la visibilidad de los atributos y métodos.
* **Validación de datos:** Se comprueba que las entradas sean numéricas y que las dimensiones de las figuras sean positivas.
* **Interfaces gráficas:** Se utiliza Swing para facilitar la interacción con el usuario.
* **Diagramas UML:** Se representan las clases, sus relaciones, los objetos y los casos de uso.
